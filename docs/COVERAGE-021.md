# RFP-021 coverage: 59 hard requirements

One row per hard requirement in `RFP-021-ethereum-state-attestation.md`. The requirement text is abridged. The RFP text governs. F = Functionality, U = Usability, R = Reliability, P = Performance, S = Supportability, VS = Verification Security. Milestones are M0 to M7 of the proposal (`proposal/RFP-021.md`). "M0 prototype" means the work exists before the grant.

States: **measured** means a raw file exists in `evidence/`. **in tree** means the file or test exists in the repository and has not been confirmed green in this draft. **in progress** means a builder is working on it. **planned** means it is a milestone deliverable that does not exist yet. TODO-MEASURE and TODO-TEST mark a figure or a test that is still open.
