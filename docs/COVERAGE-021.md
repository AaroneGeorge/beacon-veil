# RFP-021 coverage: 59 hard requirements

One row per hard requirement in `RFP-021-ethereum-state-attestation.md`. The requirement text is abridged. The RFP text governs. F = Functionality, U = Usability, R = Reliability, P = Performance, S = Supportability, VS = Verification Security. Milestones are M0 to M7 of the proposal (`proposal/RFP-021.md`). "M0 prototype" means the work exists before the grant.

States: **measured** means a raw file exists in `evidence/`. **in tree** means the file or test exists in the repository. It is not claimed as passing unless the row cites a gate run or a raw file. **planned** means it is a milestone deliverable that does not exist yet. A figure or test that is still open is described in plain words in its row.

Status: written 2026-11-12, updated 2026-11-17 with the results of G1 (V2 real proof), G4 and G5. The "in tree" rows were not re-checked against a test run in this update. Counts: Functionality 15, Usability 6, Reliability 12, Performance 9, Supportability 11, Verification Security 6, total 59.
