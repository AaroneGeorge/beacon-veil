# RFP-022 coverage: 68 hard requirements

One row per hard requirement in `RFP-022-wrapped-erc20.md`. The requirement text is abridged. The RFP text governs. F = Functionality, U = Usability, R = Reliability, P = Performance, S = Supportability, Sec = Security, Priv = Privacy Preservation. Milestones are M0 to M8 of the combined RFP-021 and RFP-022 proposal (`proposal/README.md`; the filed issue text governs). M0: delivered baseline, the prototype and gates G1 to G5 (the work exists before the grant, $0). M1: open checks and decisions, reviewed with Logos (staged public verifier measured, outbound anchor spike, proving on the minimum machine). M2: RFP-021 public update path and a testnet instance following Sepolia. M3: RFP-021 complete. M4: RFP-022 inbound and controls. M5: RFP-022 outbound, failsafe and privacy suite. M6: Logos modules, mini-app, testnet release, deployer journey and audit package. M7: audit remediation. M8: operated reference deployment for 12 months. A row with two milestones, such as `M6, M7`, is delivered in the first and closed in the last. "M0" in a row means the work exists before the grant. The prototype is a spike: the Ethereum vault, the bridge program and the burn proof exist at spike depth, and the outbound anchor is a named stub.

States: **measured** means a raw file exists in `evidence/`. **in tree** means the file or test exists in the repository. It is not claimed as passing unless the row cites a gate run or a raw file. **partial** means some of the row is in tree or measured and the rest is planned. **planned** means it is a milestone deliverable that does not exist yet. A figure or test that is still open is described in plain words in its row.

Status: written 2026-11-12, updated 2026-11-17, and on 2026-11-18 renumbered to the M0 to M8 plan of the combined proposal, with states aligned to its requirement coverage table. The bridge is a spike: what is shown is the Sepolia vault v3, the claim in dev mode against both G4 follower runs, and the real Groth16 release (`evidence/bridge/README.md`). The rows were not re-checked against a new Foundry or LEZ test run in this update. On 2026-11-20 only row P2 gained a line, on the cost of the public update path of RFP-021 (`docs/PUBLIC-PATH.md`); the rows on a real private claim proof are unchanged. Counts: Functionality 17, Usability 10, Reliability 14, Performance 7, Supportability 4, Security 9, Privacy Preservation 7, total 68.
