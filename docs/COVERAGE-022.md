# RFP-022 coverage: 68 hard requirements

One row per hard requirement in `RFP-022-wrapped-erc20.md`. The requirement text is abridged. The RFP text governs. F = Functionality, U = Usability, R = Reliability, P = Performance, S = Supportability, Sec = Security, Priv = Privacy Preservation. Milestones are M0 to M7 of the proposal (`proposal/RFP-022.md`). The prototype is a spike: the Ethereum vault, the bridge program and the burn proof exist at spike depth, and the outbound anchor is a named stub.

States: **measured** means a raw file exists in `evidence/`. **in tree** means the file or test exists in the repository and has not been confirmed green in this draft. **in progress** means a builder is working on it. **planned** means it is a milestone deliverable that does not exist yet. TODO-MEASURE and TODO-TEST mark a figure or a test that is still open.
